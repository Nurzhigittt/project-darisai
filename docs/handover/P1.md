## Implemented

- `/brief/[lectureId]`: professor-only review of BriefNext/Handoff, with lecture title, reading time, concepts, optional exercise, provenance and decision status. Navigation is available from the lecture summary and ended lectures on professor home.
- Manual creation, editing with a reason, approval, rejection with a reason, and publication of an approved Handoff. Published materials can be edited/rejected; the UI explains that these actions revoke links and editing needs another approval. A new link for an already published material does not revoke previous links.
- Loading, empty, error, rate limit, conflict and offline states. Mutations are not automatically retried. An uncertain network outcome or conflict triggers a server refresh. Refresh discards in-memory links that may have been revoked elsewhere.
- `/handoff`: public seminar material, with a token read only from the URL fragment and sent in the redeem request body. No professor authorization is attached. Missing/malformed tokens, expired/revoked links, offline/server failure and retry are handled.
- Shared content component, EN/RU/KK copy, existing light/dark design system. The skip link focuses the main content without overwriting fragment credentials. Native dialog cancellation respects the controlled open state; primary button text has theme-aware contrast.

## API boundary

The frontend calls the existing generated contracts and P2 routes: lecture lookup, insight list/create/approve/edit/reject/publish, and public handoff redeem. The backend remains responsible for authorization, ownership and allowed transitions. No backend, generated contract, dependency or migration changes were made.

The current create endpoint produces `source=manual`. There is no invented AI-generation endpoint or production fixture fallback. The current insight response has no transcript timestamps, citations or signal evidence; these are not fabricated in the UI.

Handoff tokens are not put into queries, browser storage, logs or analytics by this flow. The fragment remains available for ordinary page refresh. Publication links live only in component memory.
