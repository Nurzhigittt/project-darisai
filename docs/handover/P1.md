## Completed screens and workflows

- `/login`, `/professor`, `/p/[lectureId]`: professor authentication, course/lecture creation, live control, QR/join code, real Signal/Ripple updates and end-lecture summary navigation.
- `/transcript/[lectureId]`: JSON import and multipart audio upload, validation, processing/degraded/error states and timestamped text.
- `/brief/[lectureId]`: BriefNext/Handoff generation, manual authoring, edit with reason, approve/reject, publish, **decision history**, and **Handoff link revocation**. New links explicitly revoke earlier links; revoked state is shown without inventing a new insight status.
- `/handoff`: public fragment-credential redemption; invalid, expired and revoked links all show a safe unavailable state without leaking server details or the token.
- `/cohort/[courseId]`: observed table plus **structural gaps**, **canonical concept titles when supplied**, and explicit `synthetic | observed | mixed` provenance. Suppressed/zero/missing values remain distinct.
- `/settings/autonomy/[lectureId]`: server-authoritative mode, counters, **eligibility**, **observation start**, **whitelisted timestamp**, policy reason, and `AUTONOMY_NOT_ELIGIBLE` handling. Locked mode is never changed optimistically.
- `/replay/[lectureId]`: local confirmed moments, transcript recap/citations, MCQ/free-text Socratic turns, template/refusal states and completion.
- `/gapcards/[lectureId]`, `/gapcards`: generated cards, keyboard flip, local rating/due dates, IndexedDB persistence, offline review and confirmed local-history deletion.
- EN/RU/KK copy, light/dark themes, mobile/desktop layout and keyboard-accessible dialogs.
- Student-first academic landing with the integrated v3 visual direction, local Geologica display font and documented design notes in `docs/design/academic-landing.md`. The existing workflows and accessibility bounds are preserved.

## Accessibility fixes

The three reported WCAG 2.2 AA failures were colour-contrast violations measured during theme changes:

1. Theme colour transitions were sampled mid-interpolation by axe. Added a short `data-theme-changing` suppression window so theme changes are atomic; ordinary transitions are preserved.
2. A queued native dialog close event could close a newly reopened confirmation. A controlled-close counter now ignores events from earlier controlled closures while preserving external native close notification, backdrop, Escape and explicit close controls.
3. The professor end-lecture dialog could be closed by an earlier pause/resume response. Only the `end` action now closes that dialog.

No axe rules were disabled, no assertions weakened, and no test skipped.

Synthetic demo/cohort data is explicitly labelled.
