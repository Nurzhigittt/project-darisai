# Database schema

PostgreSQL 16+ with the `vector` extension (pgvector 0.8.1 verified locally on PostgreSQL 18.6). The canonical DDL is [`backend/migrations/001_initial_schema.sql`](../backend/migrations/001_initial_schema.sql).

## Design rules

- UUID primary keys with `gen_random_uuid()`.
- `timestamptz` in UTC for all wall-clock timestamps.
- `bigint` milliseconds from lecture start for all lecture-time values.
- Foreign keys and `ON DELETE` rules enforce referential integrity.
- CHECK constraints validate state, language, intensity, durations and privacy-relevant shapes.
- No `students` table and no individual student signal table.
- `professors.name` is the only allowlisted personal-name column.
- `join_code` is 6 Crockford base32 characters and unique.
- Embedding dimension is fixed at **384**; HNSW cosine index is created for future RAG.

## Tables

### `professors`

| Column | Type | Notes |
| --- | --- | --- |
| `id` | uuid PK | |
| `name` | text | Legitimate professor identity; explicit privacy allowlist |
| `invite_code_hash` | text unique | Keyed HMAC-SHA256 hex, never plaintext |
| `created_at`, `updated_at` | timestamptz | |

### `courses`

`id`, `title`, `professor_id` (FK), `created_at`; unique `(professor_id, title)`.

### `lectures`

`id`, `course_id`, `professor_id`, `title`, `language` (`ru|kk|en`), `status` (`scheduled|live|paused|ended`), `join_code`, `started_at`, `ended_at`, `paused_at`, `paused_total_ms`, `is_demo`, `demo_run_id`, `accepted_signals`, `unique_participants`, `peak_active_participants`, `created_at`, `updated_at`.

Indexes: `(professor_id, created_at DESC)`, `status`, unique `join_code`.

### `transcript_segments`

`id`, `lecture_id`, `start_ms`, `end_ms`, `text`, `embedding vector(384)`, `created_at`.

Indexes: `(lecture_id, start_ms)`, HNSW `vector_cosine_ops` with `m=16`, `ef_construction=64`.

### `concepts`

`id`, `lecture_id`, `canonical_id`, `title`, `start_ms`, `end_ms`, `created_at`; index `(lecture_id, start_ms)`.

### `signal_buckets`

Primary key `(lecture_id, bucket_start_ms)`. Columns: `bucket_ms`, `signals`, `unique_tokens`, `created_at`.

Semantics: one row per 10 s bucket; `signals` is accepted signal count; `unique_tokens` is distinct temporary participants observed in that bucket. Never sum unique counts across buckets to estimate unique people.

### `lecture_minutes` (added for exact heatmap semantics)

Primary key `(lecture_id, minute_start_ms)`. Columns: `signals`, `unique_tokens`, `created_at`.

Semantics: one row per 60 s minute; `unique_tokens` is distinct within the minute. It is not a sum of 10 s uniques. Late flushes are additive for counts and use `GREATEST` for unique counts, a conservative approximation documented in code.

### `confusion_clusters`

`id`, `lecture_id`, `start_ms`, `end_ms` (nullable while open), `peak_intensity`, `unique_tokens`, `concept_id`, `created_at`, `updated_at`.

Indexes: `(lecture_id, start_ms)`, partial open-cluster index. One cluster is created per sustained threshold episode, updated while active, closed on recovery/end. Consecutive episodes receive distinct IDs.

### `insights`

Future BriefNext/Handoff storage: `id`, `lecture_id`, `kind`, `audience`, `status`, `payload jsonb`, `validation jsonb`, `source`, `created_at`, `decided_at`. No rows are generated by Phase 1.

### `concept_autonomy`

Course × concept policy: `mode` (`locked|whitelisted`), `approvals`, `rejections`.

### `cohort_stats`

Synthetic cohort aggregates: `confused_share`, `lectures`, `synthetic` default true. No student-level rows.

### `demo_fixtures`

Synthetic fixtures only: `scenario`, `key`, `payload jsonb`, `prompt_version`, `synthetic` default true.

### `schema_migrations`

Created by the migration runner: `version`, `applied_at`, `checksum`. The runner takes a PostgreSQL advisory lock, applies each unapplied file in a transaction, and rejects checksum drift.

## Aggregate semantics and limits

| Metric | Exact meaning | Limit |
| --- | --- | --- |
| `signal_buckets.signals` | Accepted signals in 10 s | Aggregate; no student rows |
| `signal_buckets.unique_tokens` | Distinct tokens in 10 s | Do not sum across buckets |
| `lecture_minutes.unique_tokens` | Distinct tokens in 60 s | Late-flush edge uses a conservative max |
| `lectures.unique_participants` | Distinct tokens over the whole lecture | Aggregate only; set from temporary Redis at finalization |
| `lectures.peak_active_participants` | Highest heartbeat-active count observed | Operational aggregate |
| `confusion_clusters.peak_intensity` | Highest Ripple intensity in the episode | Signal density, not comprehension |
| `confusion_clusters.unique_tokens` | Distinct tokens observed across the episode | Aggregate only |

## Retention

- Durable aggregate tables: retained for future Ripple/Axiom analytics.
- Temporary Redis token hashes, windows, cooldowns and buffers: TTL-based (see `ARCHITECTURE.md`).
- No production audio is ingested in Phase 1.
- Student local history stays in IndexedDB until the browser clears site data.

## Privacy verification

`app.services.privacy.find_privacy_violations` checks `information_schema` against an explicit prohibited-column set and an allowlist. `tests/integration/test_database_privacy.py` verifies the live test database and the `vector` extension. The manifest endpoint fails closed if a prohibited column appears.

## Migration commands

```bash
cd backend
python -m app.migrate
```

The runner is idempotent and safe to rerun. It is also invoked before API startup when `RUN_MIGRATIONS=true`; Compose uses a dedicated `migrate` service instead.

## P2 completion additions (migration 300)

### `canonical_concepts`

Course-level concept identity: `id`, `course_id`, `normalized_key`, `title`, `created_at`; unique `(course_id, normalized_key)`. `concepts.canonical_id` is populated by the deterministic concept catalog; existing rows are preserved.

### `insight_decisions`

Append-only audit: `id`, `insight_id`, `lecture_id`, `professor_id`, `concept_canonical_id`, `action` (`approve|edit|reject|publish|revoke`), `from_status`, `to_status`, `reason`, `content_hash`, `created_at`. No raw student content.

### `insights` additions

`concept_canonical_id` (nullable FK), `generation_key` (unique per lecture/kind when present). Deduplicates repeated generation for the same evidence set.

### `handoff_links` additions

`redeemed_at`, `redeem_count`, `last_redeemed_at`, `revoked_reason`. Raw magic tokens remain unhashed only in the response; the database stores SHA-256 hashes.

### `concept_autonomy` additions

`observation_started_at`, `whitelisted_at`, `whitelisted_by_professor_id`, `policy_reason`. `mode` remains `locked|whitelisted`.

### `cohort_stats.term_order`

Numeric ordering for consecutive-semester structural-gap detection. `synthetic=true` is retained.

### `demo_sessions`

`id`, `lecture_id` (unique), `professor_id`, `scenario`, `synthetic`, `expires_at`, `created_at`, `last_reset_at`. Demo reset/delete is scoped through this table.
